## 已生效的策略

- 最后一个推理请求**完成后**开始计时；生成中或取消排空中不触发。
- 空闲 **180 秒**：保存并提交缓存文件，然后释放会话/MTP 状态显存及 CPU 检查点。模型权重常驻。
- 空闲累计 **3600 秒**：删除快照并使缓存失效。不是落盘后再等一小时。

- 专用目录：`C:/strata-models/cache/kv`。这管理当前引擎的共享缓存，不是按每个聊天窗口独立保存。

## 实现与取舍

CUDA 虚拟地址保持不变，释放其背后的物理显存，因此已有图和模型无需重新加载。恢复被删除的缓存时，仅重建状态空间及固定初始化表，随后正常 Prefill。

快照按 8MiB 块传输并校验，临时文件完成并提交后再改名。保存失败保留原内存；损坏/缺失快照回退完整 Prefill。恢复分配失败时返回错误，磁盘快照保留以便重试。删除失败会记录日志并在空闲过期处理中重试。

这是内存管理功能，不是 Prefill 吞吐优化。当前保存整个状态/工作区分配，短对话的文件也约 1.2GiB。连续压力测试落盘约 1.8–8.3 秒，恢复约 1.4–1.6 秒；正式配置结果见上表。这些延迟会受 SSD/系统负载影响。若新请求恰好在保存期间到达，需要等待；恢复时间额外计入客户端延迟，不包括在引擎 prompt_ms 中。

快照仅供当前进程使用；正常退出会删除。进程异常停止后无法继续执行定时器，已过期遗留文件在下次启动时清理。不提供重启恢复，不删除客户端聊天记录。

本轮仅验证单 GPU、无 KV streaming、32K FP16。启用功能时会拒绝层切分、远端专家 GPU 与 KV streaming；INT8/Q4 的字节格式无需转换，但未在本轮做真实模型验证。默认关闭，可从配置删去三个新增选项并重启，恢复原有内存驻留行为。
