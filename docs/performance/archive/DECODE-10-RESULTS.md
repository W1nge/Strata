# 单并发 decode +10%：本轮完成

已完成本轮优化并应用到日常配置，普通服务在本机 8080 运行，性能诊断关闭。保持原 Q3 模型权重、量化、专家 top-k、完整目标词表及 32768 上下文。

## 最终对照

| 题集 | 原版本 token/s | 最终 token/s | 提升 |
|---|---:|---:|---:|
| 原 6 题 | 58.853 | 66.123 | +12.35% |
| 独立 8 题 | 61.265 | 67.677 | +10.47% |
| 合计 14 题 | 60.407 | 67.131 | +11.13% |

原 6 题相对上一轮记录的 **59.3596 token/s**，最终 **66.123 token/s**，也提高了 **11.39%**。独立 8 题没有参与训练驻留画像、草稿词表或参数选择。

正式确认采用保存的原始可执行文件和原配置，单请求并发、temperature=0、关闭思考、max_tokens=256；两配置各预热一轮、正式三轮，共 112 个请求，其中正式 84 个。吞吐是总生成 token / 总解码时间，不含 prefill。候选确认后回到原版本；原 6 题还有此前稳定的基准及候选重复。正式测速没有同时编译或运行其它基准。

合并三轮收益为 **11.48%、10.29%、11.64%**，按题目聚类重采样的 95% 区间为 **8.62%～14.27%**。独立 8 题均值 **10.47%**，各轮 **10.94%、9.63%、10.83%**。这些是该题集的平均收益；单题本次约 **2.13%～29.56%**，不承诺任意工作负载固定提高 10%。

## 生效的改动

- **GPU 解码内核**：单 token HC 使用已有融合路径，缩小 HC down 的分块，按 HC 流拆分归一化，融合专家激活与 q8 量化；IQ3_S 稠密矩阵跨 token 共享权重解码。通过 `--decode-tuning 31` 启用。
- **静态专家驻留画像**：独立 16 个训练请求的路由统计与原画像混合，兼顾 CPU 计算成本和专家大小。原始画像保留。
- **草稿词表**：MTP 候选词表从 248320 缩到 **88252** 项，含前 32768 个词表 ID、全部含 CJK 字符的词条、特殊符号及独立训练输出 token。使用现有 MTP 子词表接口；最终 token 仍由原模型完整词表验证。MTP 权重文件与原目录是同文件硬链接，权重数值未修改。

保留 `--native-tasks 12 --spec 4 --spec-min-p 0.8 --pcie-frac 0 --skip-empty-pcie --adapt-every 0 --host-budget-gib 10`。线程状态填充、不同 CPU 分片形状及更低草稿阈值未采用。GPU 专家完全融合、持久块和多数矩阵分块候选没有形成可用收益。

日常配置：`C:/strata-models/strata-iq3xxs-native.json`。新画像和 MTP 目录：`C:/strata-models/decode10/`。原 MTP 目录及原画像均保留。恢复参数可使用同目录附件 `strata-iq3xxs-native.before-decode10.json`；旧可执行文件在证据包及工作目录中保留。

## 回归检查

- CPU 专家池：**88,473,600** 项精确与 sentinel 比较通过，覆盖每专家 1～6 token、分片和实验形状。
- 实际集成的 IQ3_S GPU 路径：真实矩阵、8 组激活、T=1～8，**1,953,792** 项逐位有限值比较通过。HC 等局部微基准记录包含在证据包。
- 服务协议 **39 项测试通过**，Windows tiered-source 测试通过，`git diff --check` 通过。
- 二分查找与旋转列表的生成代码通过空列表、重复值、负 k、零位移等边界检查；dense-rank SQL 在 SQLite 案例上执行通过。PostgreSQL DISTINCT ON 查询做了人工语义审查，未声称在 PostgreSQL 实例执行。
- 16K／32K、10%／50%／90% 深度召回 **6/6 通过**；较长输入实际 **31,239～31,241 token**。日常模式 Paris 与 Fibonacci 检查通过。

最终组合与原配置的正式文本 **30/42** 逐字相同。其余是驻留位置及草稿窗口变化下的输出差异，因此不宣称整个组合 bit-exact。因果解释题两配置都触及 256 token 上限；这些检查是有限回归，并非完整质量评测。

## 已知稳定性限制

本轮一次原配置回测因 **0xc0000005** 中断，整次失败扫描已排除。转储落在 CPU IQ2_XS<2> 的只操作寄存器的 AVX 指令上，系统报告的异常执行地址与正常地址相差一个比特；此前另一次异常有相似记录。根因仍未确认，不能据此判定显卡或 CPU 已损坏，也不能宣称该故障已修复。后续正式确认和回归均完成。代理没有调整电压、频率、BIOS，没有安装 CUDA/WSL，也没有推送代码。

本轮未重跑整个仓库 CTest；先前 PLE parity 所需原始 fixture 缺失仍是已有验证限制。
